# Terraform Docker Lab

A hands-on Infrastructure as Code (IaC) project built using Terraform, Docker, GitHub, and GitHub Actions.

## Project Goal

This repository demonstrates how to:

- Provision Docker infrastructure using Terraform
- Deploy an Ubuntu container
- Automate deployments using GitHub Actions
- Follow enterprise DevOps best practices

## Technology Stack

- Terraform
- Docker Desktop
- Ubuntu
- Git
- GitHub
- GitHub Actions
